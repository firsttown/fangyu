作者工具

发布一条公告，
玩家就能看到。

公告会保存到 GitHub 仓库的 announcements.json，玩家打开游戏里的「公告」页即可看到历史记录。

1. 连接 GitHub

只有持有仓库写入令牌的人才能发布公告。令牌只保存在这台浏览器，不会写进游戏代码。

令牌等同于仓库写入权限。不要在公用电脑保存，不要发给别人。建议使用有效期为 90 天、仅限 firsttown/fangyu 的 Fine-grained token。

第一次使用？如何创建令牌
  1. 打开 GitHub Fine-grained token 页面。
  2. Token name 填 fangyu-announcements，Expiration 选择 90 天或自定义。
  3. Resource owner 选 firsttown。
  4. Repository access 选 Only select repositories，只勾选 firsttown/fangyu。
  5. Repository permissions 找到 Contents，设为 Read and write。
  6. Generate token，复制生成的令牌，粘贴到上面的输入框。

如果令牌泄露，立刻回到 GitHub 撤销它。

2. 发布新公告

标题和内容会按纯文本保存，换行会保留。
